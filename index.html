EMBEDDED SYSTEMS · COMPUTER VISION01

FruityVens

Connecting a fruit scale to a smarter workflow.

A connected weighing system that brings fruit identification, weight, pricing, and sales records together. I worked across the ESP32 hardware, a Gemini integration through a Rust API, and a Flutter companion app for monitoring readings and confirming sales.

SENSEESP32 + camera→IDENTIFYRust + Gemini→CONNECTFlutter + Firebase
A closer look +

The system normalizes detections into 23 fruit labels and uses five-point load-cell calibration. ESP-NOW connects the boards, while Firebase synchronization includes upload retries. The identification API uses bearer-token authentication and keeps Gemini credentials on the server.

This project brought together the details at each boundary: measurement, device communication, API handling, and a mobile interface that makes the readings useful.

ESP32 · C++ · Rust · Gemini · Flutter · Firebase

Hardware & API ↗Companion app ↗
ROBOTICS · MOTION CONTROL02

Robotic arm

Learning movement, one joint at a time.

Arduino firmware that sequences six servos and a stepper motor to move an arm’s base, shoulder, elbow, wrist, and gripper. An exercise in translating motion into deliberate, adjustable steps.

A closer look +

I implemented mirrored base-servo movement, configurable joint travel ranges, gradual servo positioning, and acceleration-controlled stepper travel. The arm follows a programmed sequence, then returns to its starting positions.

Working with the mechanisms is part of my broader interest in robot dynamics, motion planning, and control systems.

Arduino · C++ · Servo · AccelStepper

Hardware prototype
FULL-STACK DEVELOPMENT03

Ballclub

Less coordination. More time on the court.

A basketball session management platform that brings signups, player queues, approvals, and payment tracking into one workflow. Built with Vue and FastAPI, with attendance history, revenue dashboards, and CSV exports.

A closer look +

Shareable join links and configurable capacity limits support the session workflow. Owner access uses JWT authentication, bcrypt password hashing, and request rate limits.

The backend includes 56 automated API tests covering authentication and club operations, including approvals, payments, and capacity limits.

Vue 3 · FastAPI · MongoDB · Tailwind CSS
